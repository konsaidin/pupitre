# Pupitre

Тренажёр вокала в духе Yousician: пой в микрофон и попадай голосом в ноты.
Распевки и упражнения генерируются под твой диапазон и работают целиком в
браузере; свои песни обрабатываются локальным пайплайном (Demucs выделяет
вокал, pYIN снимает мелодию) — и ты поёшь их под минусовку.

Подробный план и разбивка фич: [PLAN.md](PLAN.md).

## Скачать приложение

Готовые сборки для Windows (installer/portable `.exe`) и Linux (`.AppImage`) —
на странице [Releases](https://github.com/konsaidin/pupitre/releases).
CI собирает их автоматически по тегу `v*` (см. `.github/workflows/desktop.yml`).

Приложение самодостаточно: распевки и упражнения работают сразу, а сервер
обработки песен разворачивается при первом открытии библиотеки песен (докачивает Python-окружение,
зависимости ~2.5 ГБ и ffmpeg — один раз, с прогрессом в приложении).
При желании можно указать внешний сервер в «Настройки → Сервер обработки песен».

## Запуск

Фронтенд (Node 20+):

```bash
cd apps/web
npm install
npm run dev            # http://localhost:5173
```

Бэкенд для песен (Python 3.11+, ffmpeg в PATH) — без него работают упражнения,
но не загрузка песен:

```bash
cd services/api
python3 -m venv .venv
.venv/bin/pip install fastapi 'uvicorn[standard]' python-multipart mutagen numpy scipy librosa soundfile
.venv/bin/pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
.venv/bin/pip install demucs
.venv/bin/uvicorn app.main:app --port 8000
```

Первый запуск Demucs скачает веса модели htdemucs (~300 МБ). Без
torch/demucs бэкенд тоже работает: мелодия снимается с полного микса.

## Как пользоваться

1. **Мой голос** — визард за минуту меряет диапазон (удобная нота → вниз → вверх);
   под него подстраиваются упражнения, окно пиано-ролла и октава песен.
2. **Практика → Распевки и упражнения** — длинные ноты, сирены, пятиступенные распевки,
   гаммы, арпеджио, интервалы; темп/тональность/повторы настраиваются.
3. **Мои песни** — перетащи mp3/wav/flac; после обработки мелодия автоматически
   сдвигается на целые октавы в твою зону (бейдж «±N окт.» на экране игры).
4. **Настройки → Калибровка** — спой «та» на каждый клик; поправка компенсирует
   задержку аудиотракта при подсчёте очков. Сделай её один раз.

На телефоне приложение работает строго в горизонтальном формате 16:9; при
вертикальном положении появляется подсказка повернуть устройство. Навигация —
компактная боковая панель. Если повернуть телефон во время пения, занятие встанет
на паузу. В библиотеке есть поиск и фильтры треков; настройки упражнения
открываются кнопкой «Настроить».

На главной можно послушать ноты на клавиатуре и переключить октаву. В карточках
упражнений кнопка прослушивания играет начало мелодии и подсвечивает текущую ноту.
Одновременно звучит только одно превью; при уходе с экрана звук останавливается.

Шрифт Onest и иконки Phosphor включены в сборку и работают без внешних запросов;
источники и свободные лицензии перечислены в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

🎧 Играй в наушниках — иначе микрофон слышит аккомпанемент и линия голоса прыгает.

По умолчанию ноты и линия голоса неподвижны: по странице проходит маркер времени,
а следующая страница появляется без скольжения. Переключатель «Без прокрутки»
есть в шапке игры и в «Настройки → Движение на экране»; выбор сохраняется.

У упражнения на вибрато первые 1.2 секунды каждой ноты отведены на распознавание
техники и не входят в оценку. Показатель задержки в настройках учитывает окно
анализа и сглаживание; это оценка, а не аппаратный замер всего аудиотракта.

## Проверки

```bash
cd apps/web
npm ci
npm run build:dsp   # Rust с установленной целью wasm32-unknown-unknown
npm test           # в том числе звук → настоящий WASM → игровой результат
npm run build
```

Из корня: `cargo test --manifest-path packages/dsp/Cargo.toml` и
`node --test apps/desktop/tests/backend.test.cjs`. HTTP-тесты описаны в
[services/api/README.md](services/api/README.md). CI пересобирает WASM из Rust
перед тестами и сборкой приложения.

## Структура

```
apps/web       — React/TS: пиано-ролл, упражнения, библиотека, профиль голоса
apps/desktop   — Electron-обёртка (Windows/Linux сборки)
services/api   — FastAPI + пайплайн обработки (см. services/api/README.md)
```
