# Slopsician

Тренажёр вокала в духе Yousician: пой в микрофон и попадай голосом в ноты.
Распевки и упражнения генерируются под твой диапазон и работают целиком в
браузере; свои песни обрабатываются локальным пайплайном (Demucs выделяет
вокал, pYIN снимает мелодию) — и ты поёшь их под минусовку.

Подробный план и разбивка фич: [PLAN.md](PLAN.md).

## Скачать приложение

Готовые сборки для Windows (installer/portable `.exe`) и Linux (`.AppImage`) —
на странице [Releases](https://github.com/konsaidin/slopsician/releases).
CI собирает их автоматически по тегу `v*` (см. `.github/workflows/desktop.yml`).

Приложение самодостаточно: распевки и упражнения работают сразу, а сервер
обработки песен разворачивается сам при первом запуске (докачивает Python-окружение,
зависимости ~2.5 ГБ и ffmpeg — один раз, с прогрессом в приложении).
При желании можно указать внешний сервер в «Настройки → Сервер обработки песен».

## Запуск

Фронтенд (Node 20+):

```bash
cd apps/web
npm install
npm run dev            # http://localhost:5173
```

Бэкенд для песен (Python 3.11+, ffmpeg в PATH) — без него работают упражнения,
но не загрузка песен:

```bash
cd services/api
python3 -m venv .venv
.venv/bin/pip install fastapi 'uvicorn[standard]' python-multipart mutagen numpy scipy librosa soundfile
.venv/bin/pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
.venv/bin/pip install demucs
.venv/bin/uvicorn app.main:app --port 8000
```

Первый запуск Demucs скачает веса модели htdemucs (~300 МБ). Без
torch/demucs бэкенд тоже работает: мелодия снимается с полного микса.

## Как пользоваться

1. **Мой голос** — визард за минуту меряет диапазон (удобная нота → вниз → вверх);
   под него подстраиваются упражнения, окно пиано-ролла и октава песен.
2. **Распевки и упражнения** — длинные ноты, сирены, пятиступенные распевки,
   гаммы, арпеджио, интервалы; темп/тональность/повторы настраиваются.
3. **Песни** — перетащи mp3/wav/flac; после обработки мелодия автоматически
   сдвигается на целые октавы в твою зону (бейдж «±N окт.» на экране игры).
4. **Настройки → Калибровка** — спой «та» на каждый клик; поправка компенсирует
   задержку аудиотракта при подсчёте очков. Сделай её один раз.

🎧 Играй в наушниках — иначе микрофон слышит аккомпанемент и линия голоса прыгает.

## Структура

```
apps/web       — React/TS: пиано-ролл, упражнения, библиотека, профиль голоса
apps/desktop   — Electron-обёртка (Windows/Linux сборки)
services/api   — FastAPI + пайплайн обработки (см. services/api/README.md)
```
