# Slopsician — план

Аналог Yousician для вокала: загружаешь песню, приложение выделяет вокал, строит
карту нот (MIDI), а ты поёшь в микрофон и попадаешь голосом в ноты.

## Решения

- **Платформа:** веб-приложение (Web Audio API + AudioWorklet для realtime).
- **Пайплайн обработки:** локальный, open-source — Demucs (стемы) + Basic Pitch /
  CREPE+pYIN (вокал → ноты).
- **Стек:** React + TypeScript фронт, Python (FastAPI) бэк.

## Архитектура

```
apps/web        — React/TS: экран игры, библиотека, загрузка
services/api    — FastAPI: очередь обработки, отдача карт и аудио
services/worker — Python: Demucs → pitch-трекинг → сегментация → song map JSON
```

### Формат карты песни (song map)

```json
{
  "songId": "...", "title": "...", "bpm": 120, "durationMs": 214000,
  "notes": [
    { "startMs": 12040, "durMs": 480, "midi": 62, "lyric": "hel-" }
  ]
}
```

### Оффлайн-пайплайн (worker)

1. Вход: аудиофайл (mp3/wav/flac).
2. `htdemucs` → `vocals.wav` + `no_vocals.wav` (инструментал для игры).
3. Pitch-трекинг вокала: Basic Pitch как baseline; при шумной карте —
   CREPE/pYIN f0-контур + своя сегментация (медианное сглаживание, порог
   voiced-confidence, слияние коротких нот, привязка к полутонам).
4. Пост-обработка: убрать ноты <80 мс, склеить глиссандо, нормализовать октавы.
5. Результат: song map JSON + два аудиофайла, статус задачи по polling/SSE.

### Реалтайм (браузер)

- `getUserMedia` → AudioWorklet → pitch detection (`pitchy` / McLeod для старта,
  CREPE-tiny через ONNX Runtime Web — апгрейд).
- Целевая латентность детекции < 50 мс; калибровка задержки вывода звука.
- Сглаживание f0, октавная коррекция относительно ожидаемой ноты.

### Скоринг

- Попадание: |cents(голос − нота)| ≤ допуск (100 центов новичок → 35 про).
- Очки за долю длительности ноты в допуске + бонус за стабильность.
- Режим «игнорировать октаву» для новичков.

## Фичи → подфичи (пользовательские сценарии)

### 1. Профиль голоса и диапазон
Как пользователь я хочу, чтобы приложение знало, где мой голос, и подстраивало всё под него.

- **Визард диапазона.** Открываю «Мой голос» → пою удобную ноту → приложение
  показывает её вживую → веду голос вниз до предела → вверх до предела.
  Засчитываются только удержанные ≥0.5 с ноты. В конце вижу: «Твой диапазон
  A2–E4 (типичный баритон)».
- **Живая шкала.** Во время визарда — вертикальная клавиатура с бегущей меткой
  моего голоса, достигнутые границы подсвечиваются.
- **Профиль хранится** локально; можно перепройти визард в любой момент.
  Пока диапазон не определён — приложение мягко ведёт в визард перед первой игрой.
- **Комфортная зона** = диапазон минус полтона с краёв; в неё транспонируются
  упражнения и песни.

### 2. Пиано-ролл и октавная логика
Как пользователь я хочу видеть только «мою» полосу нот, а не рояль на 88 клавиш,
и чтобы песня, спетая женским голосом, сама легла в мой мужской диапазон.

- **Окно по диапазону.** Вертикальная ось — только мой диапазон ± 2 полутона.
  Слева — мини-клавиатура с подписями нот (C3, D3…).
- **Автовыбор октавы.** При загрузке карты приложение считает, каким глобальным
  сдвигом на N октав мелодия максимально влезает в мою комфортную зону, и
  сдвигает всю карту целиком (контур мелодии не ломается). Показывает бейдж
  «−1 октава» с возможностью сменить вручную (±).
- **Октавно-терпимый матчинг.** Если я пою верную ноту, но октавой выше/ниже —
  на уровнях «новичок/средний» это засчитывается, линия голоса рисуется
  свёрнутой к ближайшей октаве целевой ноты (с пометкой). На «про» — не
  засчитывается.
- **Выход за окно.** Если голос ушёл за пределы окна — стрелка-индикатор у края.
- **Линия голоса.** Хвост последних ~3 секунд: зелёная в допуске, серая мимо.
- **Бегущая линия «сейчас»** на ~30% ширины; ноты плывут справа налево;
  активная нота подсвечена, попадание заливает её прогрессом.

### 3. Игра и скоринг
Как пользователь я хочу честную и понятную оценку, из которой ясно, что чинить.

- **Допуски по сложности:** новичок ±100 центов + игнор октавы; средний ±60 +
  игнор октавы; про ±35, октава обязана совпасть.
- **Очки за ноту** = доля длительности ноты, спетая в допуске; ≥80% — «Perfect»,
  ≥50% — «Good», иначе «Miss»; всплывающий фидбек над нотой.
- **Комбо** за подряд Perfect/Good, множитель очков.
- **Пауза/выход** в любой момент; обратный отсчёт 3-2-1 при старте и после паузы.
- **Итоговый экран:** очки, % попадания, разбивка Perfect/Good/Miss, звёзды
  (1–3), график «моя линия vs ноты» на всю песню, кнопки «ещё раз» / «в меню».
- **История результатов** по каждой песне/упражнению, лучший результат виден в
  библиотеке.

### 4. Распевки и упражнения
Как пользователь я хочу размяться и тренировать слух без загрузки песен —
упражнения генерируются под мой диапазон и играются сразу.

- **Распевки:** длинные ноты (удержание 2–4 с), сирены (глиссандо вверх-вниз),
  пятиступенные распевки (до-ре-ми-фа-соль-фа-ми-ре-до) с повышением на полтон.
- **Гаммы:** мажор/минор вверх-вниз в моей тональности и темпе.
- **Интервалы:** играется опорная нота → спой ноту на терцию/квинту/… выше.
- **Арпеджио:** трезвучия вверх-вниз.
- **Настройки перед стартом:** темп, тональность (по умолчанию — от нижней
  комфортной ноты), число повторов.
- **Синтезированный аккомпанемент:** опорные ноты играются встроенным синтом
  (можно выключить «подсказку»), метроном.
- Скоринг и экраны — те же, что в песнях.

### 5. Песни (загрузка и библиотека)
Как пользователь я хочу закинуть mp3 и через пару минут петь эту песню.

- **Загрузка файла** (mp3/wav/flac/m4a) перетаскиванием; вижу этапы: «разделяю
  вокал → снимаю мелодию → готово» с прогрессом.
- **Библиотека:** карточки песен со статусом, длительностью, моим лучшим
  результатом; удаление песни.
- **Экран игры:** инструментал играет синхронно с картой; ноты — из вокала;
  октавный сдвиг применён автоматически (см. §2).
- **Обработка на сервере:** Demucs (если доступен) → pYIN f0 → сегментация в
  ноты → карта; без Demucs — pYIN по полному миксу (хуже, но работает).

### 6. Калибровка и настройки
- **Калибровка задержки:** тест «пой в метроном»/клик-тест, смещение хранится и
  применяется к скорингу.
- **Выбор микрофона**, индикатор уровня входа, предупреждение «надень наушники»
  при первой игре без них (echo).
- **Настройки сложности** глобально и на игру.

### Позже (не в этой очереди)
- Time-stretch/луп фраз, караоке-слоги (WhisperX), pitch-shift инструментала,
  вибрато-фидбек, YouTube-импорт, дуэты.

## Очерёдность реализации

1. Каркас веб-приложения + аудиодвижок (микрофон, AudioWorklet, YIN/MPM детектор).
2. Визард диапазона голоса (§1) — первая живая фича end-to-end.
3. Пиано-ролл + игровой цикл + скоринг (§2, §3) на упражнениях.
4. Распевки/упражнения полностью (§4) — приложение полезно уже без бэка.
5. Бэкенд: пайплайн песен + загрузка + библиотека (§5).
6. Калибровка и настройки (§6).

## Риски

- Basic Pitch на вокале даёт дробленые/лишние ноты — заложена своя сегментация
  поверх f0 как план Б (скорее всего понадобится).
- Demucs на CPU — минуты на трек; ок для MVP, дальше GPU или кэш популярных песен.
- Эхо: голос из колонок попадает в микрофон — рекомендовать наушники,
  echoCancellation в constraints.
- Латентность браузерного аудио разная по устройствам — калибровка обязательна в MVP.

## Порядок работ

1. Скелет монорепо + worker-пайплайн CLI (файл → song map) — можно проверять на глаз.
2. Фронт: рендер карты + плеер инструментала (без микрофона).
3. Realtime pitch + отрисовка линии голоса.
4. Скоринг + итоговый экран + калибровка. ← конец MVP
5. Волна 2 по списку.
